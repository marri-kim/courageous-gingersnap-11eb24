# AI 첫걸음 — 간단한 웹사이트

초·중학생도 볼 수 있는 AI 소개 및 3문항 퀴즈 예제입니다.

## 실행하기

1. `index.html` 파일을 다운로드합니다.
2. 파일을 더블클릭해서 Chrome, Edge, Safari 등의 브라우저로 엽니다.
3. **AI 알아보기** 버튼과 **미니 퀴즈** 기능을 확인합니다.

별도 설치, 계정 생성, API 키, 인터넷 연결 없이 동작합니다.

## 파일 구성

- `index.html`: HTML(구조), CSS(디자인), JavaScript(퀴즈 기능)가 모두 들어 있는 단일 파일

## 배포할 때

GitHub 저장소에 `index.html`을 올려 GitHub Pages로 배포하거나, Vercel/Netlify 등의 정적 웹 호스팅 서비스를 사용할 수 있습니다.

이 페이지는 첫 제작 연습용이며, 별도의 사용자 계정이나 데이터 수집 기능이 없습니다.
